## 🇬🇧 ENGLISH

### What Is RENDER BEAST?

RENDER BEAST is not a prompt generator. It is not a template engine. It is not a list of aesthetic keywords.

RENDER BEAST is an intelligent creative production system built as a Claude Code skill — it transforms vague human imagination into extraordinary creative specifications and production-ready outputs. It thinks like a world-class creative studio: challenging weak concepts, identifying generic patterns, and proposing directions that look intentionally crafted by exceptional human creative teams.

> **Central Philosophy:** Never generate something that simply looks AI-generated. Generate something that looks intentionally created by an exceptional human creative team.

---

### The Four Creative Engines

#### 🖼️ IMAGE BEAST — Elite Image Generation Direction
Transform any image idea into a comprehensive art direction package: creative concept, 17-point visual specification, model-optimized generation prompt, negative constraints, composition guide, technical parameters, and post-production instructions.

Supports: photorealistic photography, commercial and editorial photography, product photography, architecture visualization, character design, concept art, fantasy and sci-fi artwork, illustration, anime, graphic design, posters, advertising campaigns, packaging, brand visuals, editorial layouts, social media graphics, infographics, environmental artwork, fashion imagery, and food photography.

#### 🎬 CINEMA BEAST — Professional Film & Motion Production
Every video is designed as a cohesive sequence, not a collection of random shots. CINEMA BEAST builds complete pre-production packages: creative brief, storyline, emotional arc, visual treatment, scene-by-scene breakdown via the TIMELINE ENGINE, cinematography plan, shot list, continuity specification, sound design brief, and music direction.

Supports: cinematic films, brand advertisements, product commercials, short-form videos, social media content, explainer videos, motion graphics, logo animations, music videos, game trailers, film trailers, documentary sequences, product showcases, 3D animations, and architectural walkthroughs.

#### 🧊 DIMENSION BEAST — 3D Asset Creation & Visualization
Full pipeline from geometry specification to rendering. Provides: geometry spec (dimensions, topology, polygon budget), material spec (full PBR workflow), lighting design, technical specification (formats, UV, LOD, rigging), render setup, and implementation code for Blender (Python), Three.js, and React Three Fiber.

Supports: product modeling, character modeling, props, vehicles, furniture, architecture, environment design, game assets, stylized objects, photorealistic objects, hard-surface and organic modeling, procedural modeling, 3D motion assets, and interactive 3D experiences.

#### 🌐 EXPERIENCE BEAST — World-Class Digital Products & Websites
Every website gets a distinct visual identity — no cookie-cutter hero sections, no generic card grids, no default gradient backgrounds. EXPERIENCE BEAST builds from positioning and information architecture through design system creation, component architecture, responsive implementation, accessibility, and performance optimization.

Supports: landing pages, corporate websites, portfolio websites, SaaS platforms, dashboards, e-commerce, editorial websites, interactive storytelling, web applications, product showcases, immersive experiences, and experimental interfaces.

### The Anti-Slop Defense System

RENDER BEAST contains a dedicated 6-stage Anti-AI-Slop Defense System that actively identifies and eliminates:

- Generic purple-blue gradients without purpose
- Random neon accents and glow effects
- Excessive glassmorphism
- Unnecessary floating geometric decorations
- Repetitive card layouts
- Over-smooth, over-symmetric AI illustration style
- Generic stock-photo compositions
- Poor visual hierarchy and incoherent lighting

**The 6-Stage Anti-Slop Process:**

| Stage | Name | Action |
|---|---|---|
| 1 | DETECT | Identify generic visual patterns |
| 2 | DIAGNOSE | Explain exactly why it's weak |
| 3 | MUTATE | Develop a more original direction |
| 4 | REFINE | Improve every component |
| 5 | VALIDATE | Run quality scoring |
| 6 | ITERATE | Never approve weak output |

Activate directly:
```
/anti-slop [paste your existing concept or prompt]
```

### Limitations

1. **Tool Access** — RENDER BEAST provides specifications and prompts; actual generation requires connected tools (Midjourney, Runway, Blender, etc.)
2. **3D Assets** — Can generate Blender Python code and Three.js components, but cannot produce downloadable 3D files directly
3. **Text in Images** — AI image generators vary in text rendering capability; RENDER BEAST provides post-production strategies when generators fall short
4. **Video Continuity** — Clip-based generators may have continuity challenges; RENDER BEAST provides detailed continuity specifications
5. **Real-Time Rendering** — Complex Three.js/WebGL scenes require capable hardware; performance budgets are always specified

---

### Troubleshooting

**Output still looks generic:**
→ Run `/anti-slop` on the result  
→ Request `/creative-explore` for three distinct directions  
→ Provide more specific creative constraints and reference points

**Wrong image composition:**
→ Request a detailed composition specification separately  
→ Specify the exact rule (rule of thirds, centered, etc.) explicitly

**Website code not rendering:**
→ Specify the target framework explicitly  
→ Request a minimal reproduction first  
→ Check browser console and share errors

**Quality score below 85:**
→ Request the mandatory improvement plan  
→ Ask RENDER BEAST to iterate on the specific failing categories

### Apa Itu RENDER BEAST?

RENDER BEAST bukan sekadar generator prompt. Bukan mesin template. Bukan kumpulan kata kunci estetika.

RENDER BEAST adalah sistem produksi kreatif cerdas yang dibangun sebagai skill Claude Code — mengubah imajinasi manusia yang samar-samar menjadi spesifikasi kreatif yang luar biasa dan output siap produksi. Ia berpikir seperti studio kreatif kelas dunia: menantang konsep yang lemah, mengidentifikasi pola generik, dan mengusulkan arah visual yang terasa seperti karya tim kreatif manusia yang exceptional.

> **Filosofi Utama:** Jangan hasilkan sesuatu yang hanya terlihat seperti dibuat AI. Hasilkan sesuatu yang terlihat diciptakan secara intentional oleh tim kreatif manusia yang luar biasa.

### Sistem Anti-AI-Slop

RENDER BEAST memiliki sistem Anti-AI-Slop Defense 6 tahap yang aktif mengidentifikasi dan mengeliminasi:

- Gradien ungu-biru generik tanpa tujuan
- Neon accent dan glow effect yang tidak perlu
- Glassmorphism berlebihan
- Dekorasi geometris melayang yang tidak bermakna
- Layout card yang repetitif
- Gaya ilustrasi AI terlalu halus dan terlalu simetris
- Komposisi bergaya stock photo
- Hierarki visual yang buruk dan pencahayaan yang tidak koheren

**6 Tahap Proses Anti-Slop:**

| Tahap | Nama | Tindakan |
|---|---|---|
| 1 | DETECT | Identifikasi pola visual generik |
| 2 | DIAGNOSE | Jelaskan dengan tepat mengapa ia lemah |
| 3 | MUTATE | Kembangkan arah kreatif yang lebih original |
| 4 | REFINE | Perbaiki setiap komponen |
| 5 | VALIDATE | Jalankan scoring kualitas |
| 6 | ITERATE | Jangan pernah menyetujui output yang lemah |

Aktifkan langsung:
```
/anti-slop [tempel konsep atau prompt yang ingin diaudit]
```

### Keterbatasan

1. **Akses Tool** — RENDER BEAST menyediakan spesifikasi dan prompt; generasi aktual memerlukan tool yang terhubung (Midjourney, Runway, Blender, dll.)
2. **Aset 3D** — Dapat menghasilkan kode Python Blender dan komponen Three.js, namun tidak dapat langsung memproduksi file 3D yang bisa didownload
3. **Teks dalam Gambar** — Generator gambar AI memiliki kemampuan berbeda dalam rendering teks; RENDER BEAST menyediakan strategi post-production ketika generator tidak mampu
4. **Kontinuitas Video** — Generator berbasis klip mungkin memiliki tantangan kontinuitas; RENDER BEAST menyediakan spesifikasi kontinuitas terperinci
5. **Real-Time Rendering** — Scene Three.js/WebGL yang kompleks memerlukan hardware yang mumpuni; performance budget selalu ditentukan

### Pemecahan Masalah

**Output tetap terlihat generik:**
→ Jalankan `/anti-slop` pada hasilnya  
→ Minta `/creative-explore` untuk tiga arah yang berbeda  
→ Berikan constraint kreatif yang lebih spesifik

**Prompt gambar menghasilkan komposisi yang salah:**
→ Minta spesifikasi komposisi terperinci secara terpisah  
→ Tentukan rule komposisi (rule of thirds, centered, dll.) secara eksplisit

**Kode website tidak render dengan benar:**
→ Tentukan framework target secara eksplisit  
→ Minta versi minimal terlebih dahulu  
→ Periksa browser console dan bagikan error-nya

**Skor kualitas di bawah 85:**
→ Minta improvement plan yang wajib disediakan  
→ Minta RENDER BEAST untuk iterasi pada kategori yang gagal
